Règles de confidentialité — Diffuseur

Dernière mise à jour : 25 octobre 2026

1. Qui sommes-nous

« Diffuseur » est un outil personnel développé et utilisé par Matthis Pondaven. Il tourne uniquement sur l'ordinateur de Matthis Pondaven et sert à publier ses propres vidéos sur ses propres comptes YouTube, Instagram, Facebook, TikTok et LinkedIn, via les API officielles de ces plateformes.

2. Données utilisées

Diffuseur n'utilise que les données du compte de Matthis Pondaven, avec son autorisation explicite donnée sur la page officielle de chaque plateforme :

  • les jetons d'accès (« tokens ») qui permettent de publier sur ses comptes ;
  • le nom et la photo du compte connecté, pour vérifier qu'il s'agit du bon compte ;
  • les vidéos, miniatures, titres, descriptions et commentaires qu'il choisit de publier.

Diffuseur ne collecte aucune donnée de tiers (spectateurs, abonnés, autres utilisateurs).

3. Stockage

Toutes les données sont stockées uniquement en local, sur l'ordinateur de Matthis Pondaven. Aucun serveur externe ne les reçoit, à part les plateformes elles-mêmes au moment de la publication.

4. Partage

Aucune donnée n'est vendue, louée ni partagée avec qui que ce soit. Elle n'est utilisée à aucune fin publicitaire.

5. Données Google / YouTube

L'utilisation des données reçues des API Google respecte les Règles relatives aux données utilisateur des services d'API Google, y compris les exigences d'utilisation limitée. Diffuseur utilise les services d'API YouTube : en l'utilisant, vous acceptez les Conditions d'utilisation de YouTube et les Règles de confidentialité de Google.

6. Supprimer l'accès

L'accès peut être retiré à tout moment depuis les réglages de chaque plateforme (par exemple myaccount.google.com/permissions pour Google). Les jetons stockés en local sont alors supprimés de l'ordinateur.

7. Contact

Matthis Pondaven — matthispondavenpro@gmail.com

Privacy Policy — Diffuseur

Last updated: October 25, 2026

1. Who we are

"Diffuseur" is a personal tool built and used by Matthis Pondaven. It runs only on Matthis Pondaven's own computer and is used to publish his own videos to his own YouTube, Instagram, Facebook, TikTok and LinkedIn accounts, through the official APIs of these platforms.

2. Data used

Diffuseur only uses data from Matthis Pondaven's own accounts, with his explicit authorization given on each platform's official page:

  • the access tokens that allow publishing to his accounts;
  • the name and profile picture of the connected account, to check that it is the right account;
  • the videos, thumbnails, titles, descriptions and comments he chooses to publish.

Diffuseur does not collect any third-party data (viewers, followers, other users).

3. Storage

All data is stored locally only, on Matthis Pondaven's computer. No external server receives it, except the platforms themselves at publishing time.

4. Sharing

No data is sold, rented or shared with anyone. It is not used for any advertising purpose.

5. Google / YouTube data

Diffuseur's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Diffuseur uses YouTube API Services: by using it, you agree to the YouTube Terms of Service and the Google Privacy Policy.

6. Revoking access

Access can be revoked at any time from each platform's settings (for example myaccount.google.com/permissions for Google). Locally stored tokens are then deleted from the computer.

Matthis Pondaven — matthispondavenpro@gmail.com
